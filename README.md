## 当前赛事环境的已知约束

根据现有训练营规则资料，要求使用 GPT-Station 工作站、KCoder 智能体平台；远程操作须经批准的 KCoder 连接器（飞书/企业微信），禁止第三方远控。模型、依赖联网、摄像头、夜间任务额度及移动端/中继功能仍需以技术组通知确认。不要因本文有某个开源方案就推定它一定获准部署。

## 资料分类

- **实际参赛作品/项目**：能从赛事官方或项目作者材料确认与比赛关联。
- **官方技术样例**：SDK、框架和教程 Demo，不等于参赛作品或获奖项目。
- **社区项目/灵感**：能参考玩法，但未确认参与过某场比赛。
- **活动/组织仓库**：赛制、报名或基础设施资料，不是作品源码。

各文档会标明分类和可信度，避免将以上类型混为一谈。
